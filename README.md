# 🎮 Toon Mini Game (Altın Toplama Oyunu)

Unity kullanılarak geliştirilmiş, toon çevre tasarımlarına ve animasyon geçişlerine sahip eğlenceli bir 3D mini platform / altın toplama oyunudur. Bu proje, oyun geliştirme temellerini pekiştirmek amacıyla bir sınav ödevi olarak hazırlanmıştır.

---

## ✨ Özellikler

* **Karakter Animasyonları:** `Animator Controller` ile yönetilen `Idle`, `Run` ve `Victory` animasyon geçişleri (`isRunning` ve `isWin` parametreleri ile).
* **Toon Çevre Tasarımı:** Projeye özel toon çevre assetleri ve uygun shader yapılandırmaları.
* **Oyun Mekanikleri:** Altın toplama sayacı ve bölüm bitiş / başarı paneli.
* **Optimizasyon:** Temiz proje yapısı ve GitHub entegrasyonu (`.gitignore` ile optimize edilmiştir).

---

## 🛠️ Kullanılan Teknolojiler ve Araçlar

* **Oyun Motoru:** Unity
* **Programlama Dili:** C#
* **Versiyon Kontrolü:** Git & GitHub
